# CPU clock diagnostic overlay

Copy `MIPS_NATIVE/cpu_clock_probe/` to the console SD card's `MIPS_NATIVE/`.
Run the binary from Shell or Tiny MC. A new report appears in the tool's own
`diagnostics/` directory. No existing application files need to be replaced.

Source and interpretation limits are in `homebrew/cpu_clock_probe/README.md`.
This overlay is a diagnostic tool, not a CPU overclock or firmware patch.
