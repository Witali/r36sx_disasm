# Disassembly Results

This directory is organized by source:

| Directory | Contents |
| --- | --- |
| `dos/` | Disassembly/decompilation outputs for DOS programs. |
| `disk_image/kernel/` | Kernel/uImage payload analysis from the SD-card disk image. |
| `disk_image/mips_elf/` | MIPS Linux ELF executables and shared libraries from the SD-card disk image. |
| `disk_image/pe/` | PE/Windows executables found in the SD-card disk image. |
| `mtd/` | Disassembly, strings, scans, and notes for MTD/NOR dump files. |

Raw input files should stay in their original source directories. Put generated
analysis artifacts here.
